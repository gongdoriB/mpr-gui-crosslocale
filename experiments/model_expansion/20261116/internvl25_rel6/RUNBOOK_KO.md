# InternVL2.5-8B 6개 언어 REL O/R/C/F: 서버 실행 순서 (로컬 준비만 끝남, 서버 미업로드)

## 올릴 파일

| 파일 | 크기 | 필수 | 내용 |
|---|---|---|---|
| `internvl25_rel6_addon_20261116.tar.gz` | 약 4 MB | 예 | 새 코드 2개, 6개 언어 조건 파일(52,572행), 무결성 목록, 실행·점검 스크립트 |
| `internvl25_rel6_frja_images_20261116.tar` | 약 749 MB (729장) | 아니오 | fr/ja 스크린숏. 없으면 큐가 허깅페이스에서 받는다(같은 sha256 검사) |
| `queue_internvl25_rel6.sh` | 약 25 KB | 예 | 큐 스크립트 |

세 파일 모두 `/workspace`에 둔다. 해시는 `SHA256SUMS`에 있고 큐 스크립트가 시작할 때 다시 확인한다.

이미지 묶음을 올릴지 서버가 받게 할지는 사용자가 정한다. 올리면 업로드 749 MB가 들고, 안 올리면 서버가 729장을 받는다(이 경로는 가짜 응답으로만 시험했고 실제 허깅페이스 접속은 하지 않았다, 미검증).

## 실행

```
cd /workspace
bash queue_internvl25_rel6.sh --plan      # 하는 일만 출력, 아무것도 바꾸지 않음
bash queue_internvl25_rel6.sh             # tmux 안에서. 새 MINICPM_DONE이 생기고 다른 큐가 끝날 때까지 기다린다
tail -f /workspace/QUEUE8_STATUS
```

## 기다리는 신호

기본값은 `/workspace/MINICPM_DONE`이고, 파일의 수정 시각이 `WAIT_AFTER`(기본 `2026-11-16T02:11:00Z`, 지금 도는 MiniCPM r2 큐의 시작 시각)보다 늦어야 한다. 그보다 오래된 파일(이전 실패 실행이 남긴 2026-11-15의 `MINICPM_DONE` 등)은 없는 것으로 친다. 시작할 때 상태 줄에 마커 상태와 `WAIT_AFTER`를 남긴다. 신호가 있어도 `run_all_overnight.sh`나 `queue_*.sh`(`queue_minicpm_r2.sh` 포함, 이 스크립트 자신은 이름 뒤에 무엇이 붙어도 제외)가 돌고 있으면 끝날 때까지 더 기다리고, 그다음 GPU 사용이 1.5 GB 미만이 되는지 확인한다. 다른 신호로 바꾸려면 `WAIT_FOR=...`, 시각 기준은 `WAIT_AFTER=...`.

## 단계

1. 네트워크 점검(20 MB/s 미만이면 중단, `FORCE_SLOW_NET=1`로 강행).
2. 점검: 묶음 sha256, RTX 4090, 디스크 30 GB 이상, `/workspace/mpr-ivl` 존재.
3. 설정(90분 제한): 묶음이 자기 파일 밖의 경로를 담고 있으면 풀기 전에 거부한다. 풀고, 이미지 확인, 4개 언어 이미지와 6개 언어 이미지를 sha256으로 확인, venv 버전 확인.
4. 모델 내려받기(2시간 제한, 3번 재시도): 이전과 같은 리비전 `e9e4c0dc…`, 16.15 GB. 이전 실험 A 큐가 모델 캐시를 지웠다면 다시 받는다.
5. smoke: `--max-items 2`(288행, 192회, 약 1분)와 점검.
6. 본 실행: 44,489회, 제한 10시간(`FULL_H`로 변경). smoke 중앙값으로 계산한 예상 시간이 제한보다 길면 시작하지 않는다(`IGNORE_ETA=1`로 강행).
7. 완료 점검, 결과 묶음 `/workspace/queue_results/internvl25_rel6/internvl25_rel6_results_<날짜>.tar.gz`(+`.sha256`), 이 모델 캐시만 삭제, `/workspace/QUEUE8_DONE`.

결과는 `/workspace/mpr-ivl/followup_rel_6lang/results/rel6_internvl25_8b/`에 쌓인다. `followup_rel_4lang/results/` 안에는 아무것도 쓰지 않는다.

## 이어 하기, 부분 실행

- 중단되면 같은 명령을 다시 친다(예측 캐시를 이어 쓴다).
- fr 또는 ja가 들어간 행만 돌리려면 `SUBSET=new_only bash queue_internvl25_rel6.sh`(29,148행, 26,057회). 결과는 `rel6new_internvl25_8b/`에 따로 쌓인다.

## 위험과 대비

| 위험 | 크기 | 대비 |
|---|---|---|
| 디스크 | 모델 16.2 GB, 이미지 0.75 GB(묶음을 올리면 묶음 파일 0.75 GB가 더 남는다), 결과 약 0.5 GB(모의 실행에서 results.jsonl 214 MB + predictions 90 MB) | 시작 전 30 GB 점검. 다른 폴더는 지우지 않는다 |

| 시간 | 추정 약 4.0시간(아래) | 제한 10시간, ETA 점검 |

## 시간 추정 (추정치, 실측 아님)

실험 A에서 이 4090으로 잰 추론당 중앙값 0.326초를 쓴다. 44,489 × 0.326 = 14,503초 = 약 4.03시간. `new_only`는 26,057 × 0.326 = 8,494초 = 약 2.36시간. 모델 내려받기와 적재, smoke 약 1분이 따로 든다. 이 값은 실험 A의 프롬프트와 이미지 구성에서 나온 것이어서 REL(태국어·러시아어·일본어 글자가 더 긴 질문 포함)에서 달라질 수 있다.
